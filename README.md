# Sagittaire 🎯

Site de pointage de tir à l'arc, en ligne : placez chaque flèche sur la cible, suivez votre progression, réglez votre viseur et participez aux compétitions de votre club en direct.

**Site : https://yanduch.github.io/Sagittaire/**

- Pointage sur la cible avec loupe (ou pavé numérique), volées, corrections
- Blasons : WA 10 zones (122/80/60/40), 80 cm réduit, trispot, Vegas, campagne, 3D
- Rondes : WA 18 m, Vegas 300, WA 25 m, 50/60/70 m, 1440, campagne, 3D, entraînement libre
- Statistiques : progression, nuage d'impacts, groupement, conseils de visée, analyse par flèche numérotée, records
- Matériel : arcs (repères de visée par distance), jeux de flèches
- Compétitions : inscription par division, classement en direct (départage X puis 10)
